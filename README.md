# Smart IoT Weather Station

IoT-based smart weather station with multi-sensor rain detection,
real-time monitoring, and environmental data analytics.

## Project Structure

- `Backend` - Spring Boot REST API and IoT processing
- `Frontend` - React-based monitoring dashboard

## Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- WebSocket/STOMP

### Hardware
- ESP8266
- ADS1115
- Piezoelectric sensors
- DHT11
- Rain sensor
